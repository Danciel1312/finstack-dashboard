¿Cómo tener base de datos en la nube en 2 minutos gratis?
  1. Crea una cuenta gratuita en supabase.com y crea un nuevo proyecto.
  2. En el menú SQL Editor, pega el script de creación de tablas que preparamos para ti.
  3. Copia tu URL y Anon Key desde Project Settings > API y pégalos aquí arriba.
  4. ¡Listo! Cualquier cambio que hagas en tu celular se reflejará al instante en tu laptop y PC.
