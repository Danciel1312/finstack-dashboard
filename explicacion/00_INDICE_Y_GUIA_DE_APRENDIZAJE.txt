1. EL MAPA DE TU PROYECTO (CÓMO ESTÁ ORGANIZADO)
--------------------------------------------------------------------------------
Tu aplicación web funciona combinando 3 tecnologías fundamentales:

   A. HTML (El Esqueleto):
      Define qué cosas existen en la pantalla: botones, textos, tablas,
      imágenes, formularios.
      -> Archivo: `index.html`

   B. CSS (La Ropa y el Estilo):
      Define qué tan bonito se ve todo: colores, tamaños de letra, sombras,
      bordes redondeados, animaciones y adaptación a pantallas de celular.
      -> Archivos: Tailwind CSS (vía internet) + `css/styles.css`

   C. JavaScript (El Cerebro):
      Define qué pasa cuando el usuario interactúa: guardar datos al hacer clic,
      hacer cálculos matemáticos de finanzas, pintar gráficas interactivas,
      cambiar de tema oscuro a claro y mover el calendario.
      -> Archivos en `js/`: `store.js`, `charts.js`, `calendar.js`, `app.js`

   D. JSON y PWA (La Configuración):
      Permite que tu página web se convierta en una aplicación instalable en
      teléfonos celulares Android e iPhone.
      -> Archivo: `manifest.json`

3. GLOSARIO RÁPIDO DE TÉRMINOS QUE VERÁS SEGUIDO
--------------------------------------------------------------------------------
- DOM (Document Object Model):
  Es la forma en que JavaScript "ve" a tu página HTML. Gracias al DOM, JavaScript
  puede buscar un botón con `document.getElementById('miBoton')` y cambiarle el
  texto o el color.

- Variable (`let`, `const`):
  Una cajita con nombre en la memoria de la computadora donde guardas un dato
  (ejemplo: `let monto = 150.50;`).

- Función (`function`):
  Una receta de pasos que la computadora guarda para ejecutarla cuando tú
  quieras (ejemplo: `function calcularBalance() { ... }`).

- Objeto (`{ }`):
  Un paquete que agrupa varias características de una misma cosa. Por ejemplo,
  una transacción es un objeto:
  `{ concepto: "Pizza", monto: 18.00, categoria: "Alimentación" }`.

- Array o Arreglo (`[ ]`):
  Una lista ordenada de cosas. Por ejemplo, una lista de transacciones:
  `[ transaccion1, transaccion2, transaccion3 ]`.

- Evento (`Event`):
  Algo que hace el usuario: un clic con el ratón (`click`), presionar una
  tecla (`keydown`), o enviar un formulario (`submit`).

- localStorage:
  Un pequeño disco duro virtual dentro de tu navegador web donde puedes guardar
  información para que no se borre al cerrar la pestaña o apagar la PC.
